# 02 · 유형자산 취득리스트 · 감가상각대장 대사 (Python) — 복원본

## 목적

유형자산 취득리스트와 감가상각대장을 대사해, 한쪽에만 있는 자산과 금액·취득일·내용연수가 다른 자산을 예외로 정리합니다.

EY한영 반기검토(2025.07–08)에서 두 자료를 손으로 대조한 경험에서 출발해, 근무 이후 합성 데이터로 실습했습니다.

- **1차**: 취득리스트 144건 vs 감가상각대장 131건, 자산번호로 대사
- **확장 (2026.09)**: 8개 사업부, 취득리스트 5,600건 vs 감가상각대장 5,584건

당시 코드(확장 실습의 `asset_reconcile_batch.py` 포함)는 남아 있지 않아, 실습 자료의 목적과 처리 기준을 바탕으로 다시 작성한 **복원본**입니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `src/recon_basic.py` | 1차 대사 |
| `src/recon_multi.py` | 8개 사업부 확장 대사 |
| `data/basic/` | 1차 합성 입력 자료 2개 |
| `data/multi/취득리스트/`, `data/multi/감가상각대장/` | 사업부별 합성 입력 자료 각 8개 |
| `answer/` | 검증정답 (1차 13건, 확장 72건 + 사업부별 요약) |
| `results/` | 코드 실행 결과 |

## 비교 규칙

| 단계 | 대사 기준키 | 비교 항목 |
|---|---|---|
| 1차 | 자산번호 | 존재 여부 |
| 확장 | 사업부코드 + 자산번호 | 존재 여부, 취득금액, 취득일, 내용연수 |

예외유형 (확장):

| 예외유형 | 의미 |
|---|---|
| 감가상각대장 미등재 | 취득리스트에만 있음 |
| 취득리스트 미등재 | 감가상각대장에만 있음 |
| 취득금액 불일치 | 양쪽에 있으나 금액이 다름 |
| 취득일 불일치 | 양쪽에 있으나 취득일이 다름 |
| 내용연수 불일치 | 양쪽에 있으나 내용연수가 다름 |

## 예외 처리

- 키 값의 앞뒤 공백을 제거하고, 취득일은 날짜 단위로 맞춘 뒤 비교합니다.
- 같은 키가 한 자료에 두 번 나오면 대사하지 않고 오류로 멈춥니다.
- 한 자산에 예외가 여러 개면 예외마다 한 줄로 남깁니다.
- 1차에서는 감가상각대장에만 있는 자산이 있는지도 함께 출력합니다.

## 실행 방법

```
pip install -r ../requirements.txt
python src/recon_basic.py
python src/recon_multi.py
```

결과는 `results/`에 저장되고, 실행이 끝나면 검증정답과 자동으로 대조합니다.

## 검증 방법

- 1차: 미등재 13건의 자산번호가 검증정답 13건과 같은지 확인 → 일치
- 확장: 예외 72건의 (사업부코드, 자산번호, 예외유형)이 검증정답과 같은지, 사업부별 요약(8개 사업부 × 8개 항목)이 같은지, 예외별 금액·취득일·내용연수 값이 같은지 확인 → 모두 일치
- 참고: 검증정답의 '취득리스트 미등재' 8건은 대장 취득일 칸이 비어 있습니다. 코드는 원자료의 날짜를 채우므로 이 8칸은 비교에서 제외하고 그 사실을 출력합니다.
