# 01 · 기금별 자료 취합 (VBA) — 복원본

## 목적

기금별로 내려받은 엑셀 파일 여러 개에서 계정코드 `111300`(정기예금) 행만 골라 하나의 시트로 모읍니다.
파일을 하나씩 열어 추출하고 복사·붙여넣기하던 반복을, 폴더 선택 한 번으로 끝내는 것이 목표입니다.

## 실무와의 관계

- 회계법인청담 정부회계 기말감사 근무 중(2026.01–2026.03), 기존 매크로가 파일 한 개씩만 처리하던 것을 폴더 단위로 넓혀 실제 업무에 사용했습니다.
- **이 폴더의 코드는 그 원본이 아닙니다.** 원본은 회사 노트북에서 작성해 남아 있지 않습니다.
- 근무 이후 같은 업무를 합성 데이터로 다시 실습했지만, 그 실습 코드도 남아 있지 않습니다. 실습 자료의 목적과 처리 기준을 바탕으로 다시 작성한 **복원본**입니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `src/기금자료_취합.bas` | VBA 모듈 (UTF-8, 읽기용) |
| `src/excel_import/기금자료_취합_cp949.zip` | 같은 모듈의 한글 엑셀 가져오기용 파일(CP949 인코딩 `.bas`)을 압축한 것 |
| `data/` | 합성 입력 자료: 5개 기금 × 1,200행 |
| `answer/검증기준.xlsx` | 기금별 정기예금 행 수·차변 합계·대변 합계 |
| `results/VBA_취합결과.xlsx` | 매크로 실행 결과 ([통합결과], [검증요약] 시트) |
| `verify/verify_vba_result.py` | 결과를 검증기준·원자료와 대조 |

## 처리 기준

- 폴더 안의 `.xlsx` 파일을 모두 읽습니다. 임시 파일(`~$`로 시작)과 매크로 파일 자신은 건너뜁니다.
- 열 위치가 아니라 **머리글 이름**(계정코드, 차변, 대변, 기금명)으로 열을 찾습니다. 파일마다 열 순서가 달라도 같은 결과를 내기 위한 조건입니다.
- 계정코드는 숫자·문자 저장 형식이 섞여도 같은 값으로 비교합니다.
- 필수 머리글이 없는 파일은 건너뛰고, [검증요약] 시트에 그 사유를 남깁니다.
- 추출한 행에는 원본 파일명을 함께 기록합니다.

## 실행 방법

1. `src/excel_import/기금자료_취합_cp949.zip`의 압축을 풀고, 엑셀에서 새 통합문서를 열어 `Alt + F11` → 파일 → 파일 가져오기 → `기금자료_취합_cp949.bas`
2. 통합문서를 `.xlsm`으로 저장한 뒤 매크로 `취합실행` 실행
3. 폴더 선택 창에서 `data` 폴더 선택 → [통합결과], [검증요약] 시트 생성

## 검증 방법

```
python verify/verify_vba_result.py
```

- [검증요약]의 기금별 행 수·차변·대변 합계를 `answer/검증기준.xlsx`와 비교합니다.
- [통합결과] 시트를 다시 합산해도 같은지 확인합니다.
- 원자료에서 pandas로 따로 추출한 행과 전표번호 단위로 비교합니다.

결과: 477행, 5개 기금 모두 일치.

참고: 이 결과 파일은 LibreOffice의 VBA 호환 모드에서 핵심 함수(`폴더취합`)를 실행해 만들었습니다. 폴더 선택 창을 띄우는 `취합실행`은 엑셀에서 실행해 확인해야 합니다.

## 실습 범위와 복원 시 보강

- 실습에서 구현: 5개 기금 파일 일괄 처리, 111300 행 추출, 통합 시트 작성, 검증기준 대조
- 복원하면서 보강: 머리글 이름으로 열 찾기, 임시 파일 제외, 원본파일 열, [검증요약] 시트 자동 작성
