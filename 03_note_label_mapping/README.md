> 02의 취득리스트·감가상각대장 대사와는 별개의 실습입니다.

## 목적

유형자산·무형자산·충당부채 주석의 증감표를 대사할 때, 같은 의미가 다른 이름(`취득`과 `증가`, `처분`과 `감소` 등)으로 적혀 있으면 단순 문자열 비교가 실패합니다.
등록된 동의어는 표준 항목으로 맞추고, 처음 보는 표현이나 오타는 자동으로 고치지 않고 사람이 검토하도록 합니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `src/note_mapping_demo.py` | 항목명 표준화와 대사 (표준 라이브러리만 사용) |
| `src/verify_results.py` | 세 상태의 결과를 기대 결과와 대조 |
| `data/sample_notes.json` | 합성 주석 4개 (단위 백만원) |
| `results/` | 기대 결과: 매핑 전 / 동의어 매핑 후 / 오타 승인 후 |

## 매핑 규칙

| 표준 항목 | 같은 의미로 인식하는 표현 |
|---|---|
| 증가 | 증가, 취득, 당기증가, 증가액 |
| 감소 | 감소, 처분, 당기감소, 감소액 |
| 기초잔액 | 기초잔액, 기초 |
| 상각 | 상각, 감가상각, 당기상각 |
| 기말잔액 | 기말잔액, 기말 |

- 비교 전에 공백·구두점을 지우고 표기를 통일합니다(NFKC).
- 판정 순서: 사람이 승인한 표현 → 표준 항목과 정확히 같음 → 등록된 동의어 → 그 밖은 '검토 필요'
- 등록되지 않은 표현은 `difflib`으로 비슷한 후보(유사도 0.5 이상, 최대 3개)만 제시하고 자동으로 확정하지 않습니다. 사람이 `--approve 원래표현=표준항목`으로 승인해야 반영됩니다.

## 예외 처리와 계산

- 계산식: 기초잔액 + 증가 − 감소 − 상각 = 기말잔액. 이 값을 주석 기말잔액과 재무상태표 금액과 함께 대조합니다.
- 인식하지 못한 항목을 0으로 처리하지 않습니다. 필수 항목(기초잔액, 증가, 감소, 기말잔액)이 빠지거나 같은 항목이 두 번 잡히면 계산하지 않고 '검토 필요'로 남깁니다.

## 실행 방법

```
python src/note_mapping_demo.py --no-alias                 # 매핑 전
python src/note_mapping_demo.py                            # 동의어 매핑
python src/note_mapping_demo.py --approve 당기증갸=증가     # 오타를 확인한 뒤 승인
```

## 검증 방법

```
python src/verify_results.py
```

- 매핑 전: 4개 주석 모두 '검토 필요'
- 동의어 매핑 후: 3개 일치, 오타가 있는 1개는 '검토 필요' (후보: 당기증가 0.75, 당기상각 0.5, 당기감소 0.5)
- '당기증갸 = 증가' 승인 후: 4개 모두 일치 (200 + 40 − 10 = 230)
- 세 결과가 `results/`의 기대 결과와 같은지, 자체 테스트까지 확인합니다.
