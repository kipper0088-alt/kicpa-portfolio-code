# 업무 개선 실습 코드 · 이승헌 (KICPA)

회계 실무에서 반복하던 취합·대사 작업을 VBA와 Python으로 자동화해 본 실습 코드입니다.
포트폴리오 홈페이지의 체험형 데모는 이 저장소의 처리 기준을 브라우저에서 재현한 것이고, 여기에는 전체 코드와 입력 자료, 검증정답, 검증 스크립트가 있습니다.

## 코드 상태 표기

- **원본**: 당시 작성한 코드 그대로. 이 저장소에는 원본이 없습니다.
- **복원본**: 원본이 남아 있지 않아, 당시 실습 자료(README·입력 엑셀·검증정답)의 목적과 처리 기준을 바탕으로 다시 작성한 코드. 검증정답과 대조해 같은 결과를 확인했습니다.
- **재현본**: 원래 실습에서 확인된 규칙을 바탕으로 새 합성 데이터와 함께 다시 구성한 코드. 원래 코드와 같다고 주장하지 않습니다.

특히 01은 회계법인 근무 중 실제 업무에 사용한 VBA가 **아닙니다**. 그 원본은 회사 노트북에서 작성해 남아 있지 않습니다.

## 데이터

모든 입력 자료는 실습용으로 만든 **합성 데이터**입니다. 회계법인 고객사 자료나 근무 당시 파일은 포함하지 않았습니다.

## AI 활용

코드 작성, 오류 탐색, 그리고 이번 복원·재현 과정에서 생성형 AI의 도움을 받았습니다.
무엇을 비교하고 어떤 예외를 따로 볼지, 등록되지 않은 표현을 어떻게 처리할지 같은 기준은 직접 정했고, 결과는 검증정답과 대조해 확인했습니다.
